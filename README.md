# Teknikforum

En statisk, skämtsam butik för den interna IT-avdelningen. Varukorgen och dricksen finns bara i webbläsarens minne; inga beställningar skickas och inga uppgifter sparas.

## Kom igång

```sh
npm install
npm run dev
```

Bygg med `npm run build` och förhandsgranska bygget med `npm run preview`. Typsnitten hämtas från Google Fonts när sidan visas; systemtypsnitt används som reserv.
